Páginas de teste — Cenário 2

Casos de validação da auditoria de formulários da extensão Guardião Web (§4.5 do TCC).

As páginas precisam ser servidas por HTTP local, em http://localhost:8080. Abertas como arquivo (file://), os casos de destino relativo não funcionam e o Chrome não injeta o Content Script. Veja o LEIA-ME.md.

Página inicial de referência

  1. caso-00-basico.html — os três cenários originais em uma página só
    Permite o HTTPS, bloqueia o HTTP e bloqueia a requisição por fetch().

Casos individuais

  1. caso-01-action-https.html — action HTTPS
    Esperado: permite.
  2. caso-02-action-http-absoluto.html — action HTTP absoluto
    Esperado: bloqueia pelo Content Script, com alerta na página.
  3. caso-03-action-vazio.html — action vazio
    Esperado: bloqueia. O destino passa a ser a própria página, servida por HTTP.
  4. caso-04-action-relativo.html — action relativo
    Esperado: bloqueia. O caminho é resolvido contra a URL HTTP da página.
  5. caso-05-action-alterado-js.html — action trocado por JavaScript no clique
    Esperado: bloqueia. A leitura ocorre na submissão, não no carregamento.
  6. caso-06-form-dinamico.html — formulário criado após 2 segundos
    Esperado: bloqueia. Formulário ausente do HTML inicial.
  7. caso-07-formaction-botao.html — formaction HTTP no botão
    Esperado: bloqueia. O atributo do botão prevalece sobre o do formulário.
  8. caso-08-envio-com-enter.html — envio com a tecla Enter
    Esperado: bloqueia. Submissão implícita pelo teclado.
  9. caso-09-form-submit-programatico.html — form.submit() por JavaScript
    Esperado: bloqueia pela regra de rede, sem alerta visual. O evento submit não é disparado.
  10. caso-10-fetch-xhr.html — fetch() e XMLHttpRequest
    Esperado: bloqueia pela regra de rede. Confirmar na aba Rede do DevTools.
  11. caso-11-iframe-srcdoc.html — formulário dentro de iframe
    Esperado: bloqueia. Se passar, registrar como limitação conhecida.
  12. caso-12-busca-get-sem-senha.html — busca GET sem campo de senha
    Esperado: bloqueia. Caso destinado a medir falso positivo.
