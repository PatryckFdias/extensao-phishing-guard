Cenário 2: Auditoria de Formulários (§4.5)

Páginas locais para validar bloqueio de envios inseguros via HTTP.

1. Cenário de Permissão

Formulário com action="https://httpbin.org/post": envio deve ser permitido.

2. Cenário de Bloqueio Estático

Formulário com action="http://httpbin.org/post": submit deve ser bloqueado.

3. Cenário de Bloqueio Dinâmico

Botão dispara fetch() para http://httpbin.org/post: rede deve bloquear.
